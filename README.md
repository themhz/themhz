Built around:

- Next.js
- TypeScript
- PostgreSQL
- Prisma
- Payments
- Identity verification
- Real-time messaging
- Web & mobile applications
- Production Linux infrastructure

🌐 [ridonio.com](https://ridonio.com)

### 🤖 CodeCraft

Technology and AI news platform with an AI-assisted editorial workflow.

The platform uses multiple AI agents for:

`Discovery → Extraction → Analysis → Research → Writing → Editor Review`

AI generates drafts, while final publishing remains under human editorial control.

🌐 [codecraft.gr](https://codecraft.gr)

### 🥊 Gym Management Platform

Backend platform for managing boxing gyms and fitness centers.

Includes:

- Students
- Coaches
- Classes
- Attendance
- Memberships
- Payments
- Salaries
- Appointments
- Subscription management

Built with **Laravel, MySQL, Sanctum and Docker**.
